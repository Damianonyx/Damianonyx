# Geek’s Corner of the Internet

The personal portfolio of **DAMIANONYX**.

I write about AI, RWA and emerging technology, research emerging systems and build things while figuring out how they work.

My work sits around AI, Web3, technical writing, research, storytelling and the occasional experiment that probably started with “I wonder if I can build this.”

## Overview

A responsive, single-page portfolio with a monochrome pixel identity, readable typography and subtle motion. It brings together my writing, research, experiments and builds.

## Features

- A brief name reveal and animated pixel portrait that moves into the navigation when scrolling.
- A welcome greeting that cycles through English, Spanish, French, Chinese, Japanese, German, Turkish and Pidgin. Tap to pause or resume; scrolling pauses it.
- An About section with a separate personal philosophy card.
- An animated “My content” card featuring six topics: AI models, Large language models, RWA (Real World Assets), Technical writing, Crypto/blockchain and Open-source software.
- An archive with image previews, article links and repositories where supplied.
- A grid of projects I’ve worked with, linking to their X profiles.
- An audience visualisation based on the supplied three-month impressions snapshot.
- Direct contact and publication links.
- A closing “Let’s Bloom” flower animation, revealed on activation.
- Light and dark themes that remember the visitor’s explicit choice.
- Responsive mobile layouts, keyboard controls, visible focus states and reduced-motion support.
- Favicons, an Apple touch icon and social-sharing metadata.

## Run Locally

Install Node.js and npm, then download or clone this repository and open a terminal in its root directory.

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local address printed in the terminal.

To check the JavaScript syntax:

```bash
npm run check
```

## Project Files

| Path | Contents |
| --- | --- |
| `dist/index.html` | Portfolio content, links and metadata |
| `dist/style.css` | Responsive layout, themes and visual styles |
| `dist/app.js` | Greeting, portrait, topic card, archive, audience and flower interactions |
| `dist/assets/` | Images, fonts, icons and animation assets |
| `dist/site.webmanifest` | Web app metadata |
| `package.json` | Dependencies and development commands |
| `vite.config.js` | Development server configuration |

The `dist/` directory contains the editable website files and is the root served by Vite.

## Updating the Portfolio

- Edit text, project entries, image references and contact links in `dist/index.html`.
- Add new images to `dist/assets/` and provide meaningful alternative text.
- Adjust layout and appearance in `dist/style.css`.
- Adjust animation and interaction behaviour in `dist/app.js`.
- Keep article titles, descriptions and destinations aligned with the supplied work.

## Static Hosting

The portfolio can be served as a static website using `dist/` as the publish directory. The current files do not require a separate production build.

If the website moves to another domain, update the canonical URL and absolute social-sharing URLs in `dist/index.html` to match the new address.
